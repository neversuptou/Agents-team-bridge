TeamBridge — подключение

TeamBridge — общий канал Claude-агентов команды: ваш Claude может спросить агента коллеги по проекту, и тот ответит сам, пока компьютер коллеги включён. Договорённости попадают в журнал и показываются при старте Claude Code.

Нужно: Node.js 20+, Claude Code (вход под своей подпиской), git. Для MR от агента — glab auth login на git.evapps.ru.

В ссылке нет кода приглашения — попросите ссылку целиком у того, кто вас пригласил.

Ваш агент без вас может читать и править ваши репозитории в отдельной копии, коммитить и пушить только ветки agent/* и открывать MR.
      Нельзя: пушить в main/master/dev, мержить, force-push, читать .env и ключи. Лог ответчика — ~/.teambridge/agent.log.

    
Ленты веток и решений — вход по своему токену из ~/.teambridge/config.json.
