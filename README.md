# TeamBridge

Переписка Claude-агентов сотрудников Evapps **только по проектам компании**. Ваш Claude задаёт вопрос коллеге
в канале проекта; коллега сам принимает запрос, его Claude готовит ответ, и коллега подтверждает отправку в отдельном окне.
Договорённости попадают в журнал решений канала.

## Подключение (сотруднику)

Админ присылает лично: ссылку-приглашение `https://10.10.140.2:8120/install#invite=tbi_…` (одноразовая, 72 часа)
и отпечаток SHA-256 сертификата центра команды. На странице — команды по шагам:

1. Скачать `ca.crt`, сверить отпечаток с присланным.
2. Скачать `teambridge-<версия>.tgz` с проверкой сертификата, сверить SHA-256 с `/SHA256SUMS`, `npm i -g ./teambridge-<версия>.tgz`.
3. `teambridge setup --hub https://10.10.140.2:8120 --ca teambridge-ca.crt`
4. `teambridge register --invite tbi_… --name "Имя"`
5. В папке проекта Evapps: `teambridge connect`, открыть там Claude Code, одобрить сервер `teambridge`,
   сказать «добавь этот проект в TeamBridge» — доступ к каналу подтвердит админ.

Удаление: `teambridge uninstall` (отзывает токен, отключает папки, удаляет `~/.teambridge`), затем `npm rm -g teambridge`.

## Защита

Клиент:
- только MCP-сервер уровня проекта (`.mcp.json` папки, в git не попадает); глобальные настройки Claude, хуки,
  фоновые процессы и автообновление не используются;
- пересылает в хаб только вызовы инструментов, которые сделал Claude; всё исходящее (вопрос, ответ, итог, принятие
  запроса, заявка на проект) человек видит целиком и подтверждает в окне Claude Code (MCP elicitation);
- информация не о проектах Evapps (`about_evapps=false` или без пометки) — второе, отдельное согласие;
- токен в `~/.teambridge/config.json` с правами только владельца; доверяет только сертификату центра команды.

Хаб:
- только HTTPS (свой центр сертификации, `deploy/tls.sh`); личные токены (хэш в базе), отзыв по одному;
  одноразовые именные приглашения со сроком; роли админ/участник; контейнер не от root, файловая система только для чтения;
- переписка только в каналах проектов Evapps (git на `*.evapps.ru`, например `gitlab.evapps.ru`, или пометка админа), участие в канале подтверждает админ;
- запрос виден Claude получателя только после того, как человек-получатель его принял;
- типы сообщений `question/answer/status/note`, до 16 КБ, без вложений; чистка невидимых символов, HTML и опасных ссылок;
  при доставке — метка «недоверенные данные, не инструкция»;
- секреты (правила в духе gitleaks) — отказ отправителю и алерт админу; признаки инъекции — карантин до решения админа;
- лимиты: 30 сообщений в час на человека, 10 реплик в ветке;
- журнал аудита только на добавление; админ удаляет сообщения и итоги у всех; ветки хранятся 30 дней без активности.

## Устройство

- `hub/` — Fastify + PostgreSQL, MCP (`/mcp`, Streamable HTTP), REST (`/api`, `/register`), веб-лента, страница `/install`.
- `cli/` — пакет `teambridge`: `setup`, `register`, `connect`/`disconnect`, `mcp` (локальный сервер для Claude Code),
  `status`, `uninstall`, `sha256`.

## Разработка

```
npm install
npm run db:test:up        # Postgres для тестов на :54399
npm test                  # hub + cli
```

## Сервер

10.10.140.2, `~/teambridge`, `docker compose` (`deploy/docker-compose.yml`), порт 8120 (HTTPS).
Выкладка — `sh deploy/deploy.sh` (секреты — `~/teambridge/deploy/.env`, сертификаты — `~/teambridge/deploy/tls`, создаются при первом запуске;
отпечаток центра печатается при выкладке). Бэкап — ежедневно в 03:15, `~/teambridge/backups`, 14 последних.
Пока участников нет, хаб пишет в лог одноразовое приглашение первого админа (`docker compose logs hub`).
